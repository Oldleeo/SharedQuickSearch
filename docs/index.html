找一张图，本来不该这么难

设计部的共享盘，几万到几十万个文件很常见。下面这些事每天都在发生，共享速搜就是冲着它们做的。

以前用共享速搜

在资源管理器里搜共享盘，转圈几分钟，还经常搜不全。

搜的是本机建好的索引，不再翻共享盘。20 万个文件，输入后几十毫秒出结果。

同一个款，有人写 14-5，有人写 14_5、SKU145，搜一种写法漏掉另外两种。

空格、横线、下划线、点都忽略。14-5、14_5、145 找到的是同一批文件。

中文文件名要切输入法才能搜，打错一个字就没了。

拼音和首字母都能搜：bdt 就是“白底图”，zt 就是“主图”，xqy 就是“详情页”。

缩略图一张张慢慢冒出来，PSD 要等更久，翻一页等半天。

看过的图存在本机，下次 0 毫秒出现。PSD 只读文件开头存的预览图，80 MB 的文件只读约 1 KB 有效数据。

拖文件时手一抖，把共享盘上的原文件拖走了，全组找了一下午。

从共享速搜拖出去只能是复制。按着 Shift 也变不成移动，原文件永远留在原地。

找到文件名还不够，还得一层层点进文件夹，才能把文件拿出来用。

回车直接打开所在位置，双击打开文件，Ctrl+Shift+C 复制文件，到哪里都能粘贴。

每个细节都是为了少等一秒

下面是它具体怎么做的，包括数字和做不到的地方。

搜索：随手写，也能找到

第一次打开时扫描一遍共享盘，把文件名、大小、修改时间存成本机索引。之后每次搜索都只查这份索引，共享盘在不在线都能搜。

  • SKU 容错空格、横线、下划线、点都忽略，14-5 = 14_5 = 145。
  • 拼音全拼和首字母都行，多音字只认一个常用读音。
  • 逐字筛选后一个字只在上一次的结果里找，打字时通常 0–3 毫秒。
  • 分类计数图片、PSD·AI、文档、视频、文件夹，各有多少一眼看到。

5–27 ms搜“14-5”40–130 ms搜“bdt”，约 2 万条命中20 万个文件，2 核测试机

缩略图：看过的，下次不再等

每张缩略图按下面的顺序一层层找，找到就停。越往上越快，前三层完全不读文件内容。

  • 本机缓存生成过的都存在本机，默认上限 2 GB，满了删最久没看的。
  • 后台预热电脑空闲时提前生成，你一开始翻就自动暂停，不抢带宽。
  • 全组共用（可选）在共享盘上选一个专门的文件夹，一个人看过的图，其他人直接用。只往那个文件夹里写，每张约 20 KB。
  • 文件夹预览从文件夹里挑最近的 3 张图拼成预览，写着里面有多少文件，不用点进去就知道装的是什么。
  • 先糊后清JPG 先显示文件里自带的小图，后台换成清晰版，自动替换。
  • 自动转正手机和相机拍的照片按方向信息转正。

第一次见到、又没有内嵌预览的大文件（没存缩略图的 PSD、大 TIFF、视频）还是要从共享盘读，速度取决于网络和 NAS。

  1. 内存里最近的 360 张0 ms不读共享盘
  2. 本机磁盘缓存1–3 ms不读共享盘
  3. Windows 缩略图缓存几 ms只解析路径
  4. 文件头里的预览图（PSD、JPG、AI、PDF）一次网络往返只读文件开头
  5. 完整生成看文件大小读整个文件

拖出去就是复制，原文件永远不动

拖到桌面、文件夹、微信、Photoshop 都行。软件告诉 Windows 这次拖拽“只允许复制”，所以目标位置拿到的是一份副本，按着 Shift 也变不成移动。

  • 多选一起拖Ctrl 点选、Shift 连选，拖拽图会叠成一摞，角上写着数量。
  • 有反馈复制成功后卡片闪一下对勾，底栏写明复制了几个文件。
  • 不想拖Ctrl+Shift+C 复制文件，到别处 Ctrl+V 粘贴。
  • 跨 SKU 一起拿看中哪张就中键点一下，它飞进下方的收集栏。换个 SKU 继续搜、继续收集，最后一起复制或拖出。

索引自己保持最新

同事往共享盘里放了新图，一般一两秒就能搜到，不用手动刷新。

  • 实时监听新建、改名、删除、覆盖保存都会更新，变化每 4 秒合并写一次盘。
  • 定期校准每 2 小时快速核对一遍，目录没变就不列内容，多台电脑错开时间，不会一起去扫 NAS。
  • 断线也能搜NAS 离线时用上一次的快照，结果上标出“离线快照”，界面不会卡住。
  1. 同事把“14-5 主图 v4.psd”存进共享盘
  2. Windows 通知监听：这个文件夹有变化
  3. 合并这一批变化，只更新这几个文件，写进本机索引（测试里 1 秒以内）
  4. 你正在看的结果里出现这个文件，选中和滚动位置都不变

不修改共享盘上的原素材

给全组装之前，这几件事最好先说清楚。代码是开源的，每一条都可以自己去查。

会做的

  • 读取你指定文件夹里的文件名、大小、修改时间，建本机索引
  • 预览时读取文件，或者调用 Windows 自带的缩略图组件
  • 把索引、设置、缩略图缓存存在这台电脑的用户目录里
  • 只装给当前用户，不需要管理员权限
  • 如果你开着，呼出时读一次剪贴板文字，看是不是货号

不会做的

  • 不改、不删、不移动、不重命名共享盘上的原素材；全组缓存默认关闭，开启后仅写入指定缓存目录
  • 没有账号和统计，不向作者上传文件名、路径或搜索内容；网络用于共享盘、更新和可选的全组缓存
  • 不保存剪贴板内容
  • 不写系统级注册表（HKLM），不装服务
  • 卸载时不碰共享盘，只删本机的程序和快捷方式

从下载到第一次搜索

  1. 下载安装

    只有一个安装文件。默认装在你的用户目录，可以选开始菜单和桌面快捷方式。已经装过会自动升级，设置和索引都保留。

    没有代码签名，Windows 第一次可能提示“已保护你的电脑”，点“更多信息”→“仍要运行”。

  2. 跟着引导设置

    粘贴共享盘路径，比如 \\NAS\设计部，马上检查能不能连上。再选哪些文件夹不用录入，回收站、@eaDir 这类已经帮你勾好。

    第一次扫描在后台进行，速度看文件数量和网络，通常每秒几千个文件。

  3. 按快捷键开始搜

    在任何地方按 Ctrl Alt Space，输入，找到，拖走。扫描的同时会播放 5 张一分钟的动画教学。

    快捷键可以在设置里换。

目前做不到的

  • 只有 Windows 版。用的是 WPF 和 Windows 的缩略图、拖拽组件，没有 Mac 版的计划。
  • 每台电脑各自建索引。缩略图可以全组共用，但索引还是每个人自己扫一遍。
  • 全组缓存权限要单独确认。能读取缓存目录的人可能看到其中的缩略图，缓存不会自动继承每份原素材的访问限制。
  • 只搜文件名，不搜文件内容。PSD 里的图层名、PDF 里的文字搜不到。
  • 多音字只认一个读音。比如“长”只认 zhang，搜 chang 找不到。
  • 快速校准看不到“原地覆盖保存”。这类修改靠实时监听；监听断过的话，要等下一次完整扫描。
  • 没有代码签名。第一次运行 Windows 会提示一下，公司的杀毒软件也可能要求放行。

常见问题

公司电脑没有管理员权限，能装吗？

能。默认装在 %LocalAppData%\Programs\共享速搜，只写当前用户能写的位置，不写 HKLM，不装服务。

会不会把 NAS 拖慢？

第一次扫描会把每个文件夹列一遍，之后搜索完全不访问共享盘。缩略图优先读本机缓存和文件头的预览图；后台预热在你操作时自动暂停，超过 4 MB 又没有内嵌预览的文件不预热。定期校准每 2 小时一次，目录没变就不列内容，多台电脑会错开时间。

哪些格式能看缩略图？

JPG、PNG、GIF、BMP、TIFF、WebP、HEIC 直接解码；PSD、AI、PDF、INDD 优先读文件里存的预览图，没有就交给 Windows 的预览组件；视频和 Office 文件走 Windows 缩略图。PSD 想要缩略图快，Photoshop 里“首选项 → 文件处理 → 图像预览”要设成“总是存储”。

我的数据存在哪？怎么清掉？

设置、索引和收集栏路径在 %AppData%\Oldlee\共享速搜，本机缩略图默认放在 %LocalAppData%\Oldlee\共享速搜\thumbs，可在设置中换位置。全组缓存默认关闭；开启后仅在选定的 .共享速搜缓存 中写缩略图，权限由共享目录管理。卸载不删除共享盘文件。

怎么卸载？

Windows“设置 → 应用 → 共享速搜 → 卸载”。会删除程序文件、快捷方式和开机启动项，共享盘上的文件一个都不碰。

GitHub 下载很慢怎么办？

下载一次后放到共享盘里，同事从共享盘双击安装就行，安装包只有一个文件。

可以改了自己用吗？

可以。源码在 GitHub，MIT 协议，商用、修改、再分发都行，保留版权声明即可。用 .NET 8 和 WPF 写的，运行仓库里的 build.ps1 就能编译出安装包。

免费，开源，不用注册。卸载干净，不留东西在共享盘上。
